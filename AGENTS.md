# Instruções para agentes

Antes de alterar o projeto, leia `plano-de-trabalho-TC4.md`, `docs/CHECKLIST.md` e o documento
de arquitetura relacionado à tarefa.

## Regras obrigatórias

1. Preserve alterações existentes e identifique o integrante responsável pela solicitação.
2. Trabalhe em branch `<tipo>/<integrante>/<descricao-curta>`, salvo autorização explícita.
3. Não versione dados, PII, segredos, modelos, execuções MLflow ou relatórios locais sensíveis.
4. Mantenha separação entre dados de referência e dados de produção simulados.
5. Atualize o checklist somente quando status, aceite, responsável ou evidência mudar.
6. Não declare como implementado o que ainda for apenas arquitetura ou plano.
7. Execute lint e testes proporcionais à mudança.
8. Não faça push, abra PR ou merge sem solicitação explícita.
