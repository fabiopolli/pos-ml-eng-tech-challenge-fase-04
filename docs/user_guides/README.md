# Guias de uso

Guias operacionais das aplicações e ferramentas do projeto, escritas para quem vai **usar** o
repositório — e não para quem vai recuperar a arquitetura ou a governança.

| Guia | Aplicação | Para quê |
|---|---|---|
| [`laboratorio-de-modelos.md`](laboratorio-de-modelos.md) | `dashboard/app_dev.py` (Streamlit) | inspecionar, comparar e testar os modelos congelados: artefatos, comparação lado a lado, predição individual e em lote, cenários de contrato |

## Convenção

- Cada guia é autossuficiente: instala, executa, mostra o resultado esperado e declara os
  limites do que se pode afirmar.
- Comandos e caminhos são verificados por execução; números citados têm a fonte indicada.
- O que a aplicação **não** faz é parte do guia: é a informação que evita leitura errada.
- Guias de uso **não** substituem a evidência técnica nem a governança: ver
  [`docs/ARCHITECTURE.md`](../ARCHITECTURE.md), [`docs/CHECKLIST.md`](../CHECKLIST.md) e
  [`docs/GOVERNANCE.md`](../GOVERNANCE.md).
